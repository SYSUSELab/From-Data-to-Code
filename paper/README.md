# Original preprint

[From-Data-to-Code.pdf](From-Data-to-Code.pdf) is the original May 2026 preprint, also available at [arXiv:2605.05267](https://arxiv.org/abs/2605.05267). It is retained as a historical paper copy.

The repository's current documentation and result package reflect the major-revision synthesis: eight generated-code dimensions, thirteen training-data headings, and twelve relationship families. The original PDF has earlier taxonomy and mapping counts. Use the [result guide](../data/README.md) for the current package.
